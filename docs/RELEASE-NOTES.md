# v1.0.1 修正離線開啟空白頁

修正瀏覽器啟動時的 `process is not defined` 錯誤。請使用本版本取代 v1.0.0 的 index.html。原有方法論及五平台技能內容保持不變。

下載 `GartnerPreemptiveCybersecurity-offline.zip` 並解壓，直接以瀏覽器開啟 `index.html`。網站不需要伺服器或網路，五套技能可直接從頁面下載。

包含 Gartner Preemptive Cybersecurity 方法論分析、10 類 inputs、8 類 outputs、11 技術、ChatGPT／Claude／Grok／Nemotron／DeepSeek v4 五套技能，以及完整安裝、使用、API 適配、合成範例與驗收說明。

已以 Chrome 的 file:// 實測八個內容區、五份技能 ZIP 下載、JSON 檢查與手機版導覽；沒有頁面錯誤或 HTTP 請求，並已檢視桌面與手機截圖。既有 13 項資料／適配器測試、技能及內容檢查範圍見 docs/QA.md。仍未進行各平台付費推論。

保留 Gartner 原報告 SSDS／AMTD 的採用距離歧異，區分原始主張、工程推導與未驗證假說。未包含付費 PDF 或原圖。此為獨立研究與實作，非 Gartner 官方產品。
